## NASA data used

NASA Earthdata Fire Information for Resource Management System (FIRMS) active-fire detections from MODIS (Terra, Aqua) and VIIRS (Suomi NPP, NOAA-20, NOAA-21): https://firms.modaps.eosdis.nasa.gov/

The app reads delivered, fixed files built from FIRMS downloads. It does not call FIRMS. Processing types: SP = standard processing, NRT = near real time. The table is read from the `source` and `version` columns of the delivered detections file. VIIRS satellites appear under their file labels (SNPP, N20, N21).
